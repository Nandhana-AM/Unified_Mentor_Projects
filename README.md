# 🧑‍💼 Employee Attrition Prediction

This project builds a predictive model to identify employees at risk of leaving a company. By analyzing workplace attributes and demographics, HR teams can take proactive steps to improve retention.

---

## 📌 Objectives

- Predict the likelihood of employee attrition using classification models
- Understand key drivers of attrition through exploratory data analysis
- Provide actionable insights to HR and management

---

## 🧠 Methodology

1. **Exploratory Data Analysis (EDA)**
   - Visualized relationships between attrition and features such as Job Role, Age, Work-Life Balance, and Environment Satisfaction
   - Identified patterns in tenure, promotion history, and salary levels

2. **Data Preprocessing**
   - Handled missing values, encoded categorical variables
   - Removed outliers using IQR method

3. **Modeling**
   - Trained a `Random Forest Classifier` for its robustness and interpretability
   - Evaluated performance using accuracy, precision, recall, and F1-score

4. **Insights**
   - Key attrition drivers included low satisfaction scores, long overtime hours, and fewer promotions

# ⚽ FIFA Player Performance Analysis

This project analyzes FIFA player statistics to uncover performance patterns, player similarities, and clustering insights based on player attributes.

---

## 📌 Objectives

- Perform exploratory analysis on player attributes
- Visualize positional strengths and skill distribution
- Group similar players using unsupervised learning techniques

---

## 🧠 Methodology

1. **Data Cleaning & EDA**
   - Cleaned and filtered FIFA player dataset
   - Analyzed attributes by position (Defenders, Midfielders, Attackers)
   - Used correlation heatmaps and bar plots for comparison

2. **Player Clustering**
   - Standardized features
   - Applied KMeans clustering to group players into distinct skill-based clusters
   - Visualized clusters in 2D space using PCA

3. **Insight Generation**
   - Identified attributes differentiating elite players from others
   - Provided cluster-based player recommendations
